# Task 5 — Static Informational Pages

Build the public-facing info pages using a shared content page template.

## Steps

1. Create a reusable `ContentPage.tsx` template that accepts: title, breadcrumbs, body content (as structured sections), optional sidebar.
2. Build these pages (content from master DOCX or `site-content.ts`):
   - `/about` — About HOMATZ
   - `/how-it-works` — How B2B access works / platform process
   - `/faq` — Frequently asked questions (accordion component)
   - `/privacy-policy` — Privacy policy
   - `/terms` — Terms and conditions
   - `/shipping` — Shipping information
   - `/returns` — Returns policy
   - `/contact` — Contact / trade enquiry page (with enquiry form)
3. Each page uses Header, Footer, Breadcrumbs, and matches the approved design language.
4. Update Footer links to point to these pages.
5. Verify all links work from Footer and any other references.
6. `npm run build` — 0 errors.
