Section 9 — End-to-End User Journey Tests
These test complete workflows from start to finish.

Journey 1 — New Wholesale Partner
 Visit the homepage
 Click Apply → Choose "Apply as Wholesaler"
 Complete and submit the wholesale application form
 Confirm you land on the Pending page
 (Admin) Log in as admin → go to Partner Applications → Approve the application
 (Partner) Log back in → confirm you land on the Dashboard (not the Pending page)
 Browse the Price List
 Create a new Bulk Order
 View the order in the Orders list
 Open a Support Ticket about the order
 (Admin) Reply to the support ticket from the Admin panel
 (Partner) View the reply in the ticket detail
 Download an invoice for the order
 Check the Tracking page for shipment status
Journey 2 — New Dropship Partner
 Visit the homepage
 Click Apply → Choose "Apply as Dropshipper"
 Complete and submit the dropship application form
 Confirm you land on the Pending page
 (Admin) Approve the application
 (Partner) Log back in → confirm the Dropship Dashboard is shown
 Check the current balance
 Go to Top Up Funds → enter an amount → get bank transfer details
 Complete the bank transfer confirmation step
 Check the Transaction Ledger shows the pending top-up
 Verify a low balance warning appears if balance is below threshold
 Download a balance statement
Journey 3 — Rejected Applicant
 Submit a wholesale application
 (Admin) Reject the application with a reason
 (Applicant) Try to log in → confirm you see the Restricted page with the rejection reason
 Confirm you cannot access the dashboard or any portal page
Journey 4 — Admin Content Update
 Log in as admin
 Go to Categories → Edit the "Kitchen & Household" category → change the description → save
 Click "Preview" → verify the change appears on the live category page
 Go to Products → Edit a product → add a new feature bullet → save → preview
 Go to FAQ → Add a new FAQ item → verify it appears on the public /faq page
 Go to Media → Upload a new image → copy the URL → verify the image is accessible
Journey 5 — Partner Suspension
 Log in as an approved Wholesale partner → confirm dashboard access
 (Admin) Go to Partners → find the partner → click Suspend → confirm
 (Partner) Refresh the page → confirm they are redirected to the Restricted page
 (Admin) Reactivate the partner
 (Partner) Log in again → confirm dashboard access is restored
